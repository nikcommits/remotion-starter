# Video-Projekt für Mac installieren

Mit diesem Projekt erstellt eine lokale KI aus vorhandenen Videos Shorts mit der Vorlage GoldShort. Das Projekt ist für Macs mit Apple Silicon vorgesehen; ein vollständiger Test auf einem frisch eingerichteten Mac steht noch aus. Die Installation benötigt Internet, mindestens 8 GB freien Speicher und gegebenenfalls deine Bestätigung für Apples Entwicklerwerkzeuge.

## Installation

Öffne ChatGPT Desktop mit Codex beziehungsweise eine Codex-Umgebung, in der die KI **auf deinem Mac** Dateien lesen und Terminalbefehle ausführen kann. Ein normaler Chat ohne diesen Zugriff kann das Projekt nicht selbst installieren. Sende der KI folgenden Text:

> Installiere dieses Video-Projekt auf meinem Mac: https://github.com/nikcommits/remotion-starter
> Lies zuerst START-HIER.md, richte das Projekt ein und prüfe es mit dem Beispielvideo. Erkläre mir alle Schritte, bei denen ich etwas bestätigen muss.

Die KI lädt das Projekt herunter und führt dich durch die Einrichtung. Der erste Start kann wegen der Downloads dauern. Falls macOS nach einer Freigabe fragt, zeige der KI die Meldung und bestätige erst, wenn du sie verstanden hast. Für dieses öffentliche Repository brauchst du keine GitHub-Anmeldung.

## Neuen Short erstellen

> Erstelle einen Short aus meinem Video [Pfad oder Dateiname], von [Startzeit] bis [Endzeit]. Verwende GoldShort und zeige mir Untertitel und Vorschau zur Prüfung. Exportiere danach das fertige Video.

Prüfe die vorgeschlagenen Untertitel und Schnittgrenzen anhand des Tons und gib sie ausdrücklich frei. Die KI erklärt dir, wo die fertige MP4 liegt. Dein Original bleibt erhalten.
